# Estudo de Automação com Grunt.js

Este repositório documenta meus estudos e testes com o **Grunt.js**, um executor de tarefas usado para automatizar processos no desenvolvimento front-end.

## 🎯 Objetivo do Estudo

Explorar e configurar um fluxo de automação para tarefas comuns de front-end, visando otimizar o tempo de desenvolvimento e garantir boas práticas.

## ⚙️ Tarefas Automatizadas (Testadas)

Neste projeto, configurei tarefas do Grunt para:

- **Minificação de arquivos CSS e JavaScript** (para produção)
- **Otimização de imagens**
- **Compilação de SASS/LESS** (convertendo para CSS)
- **Live reload** do navegador durante o desenvolvimento
- **Uglify** para compressão de código JS

## 🛠️ Tecnologias e Ferramentas

- Grunt.js
- Node.js / npm
- HTML5
- CSS3 / SASS
- JavaScript

## 🚀 Como Executar (para referência futura)

1.  Certifique-se de ter o [Node.js](https://nodejs.org/) instalado.
2.  Clone este repositório.
3.  Instale as dependências: `npm install`
4.  Execute o Grunt: `grunt` (ou a tarefa específica configurada)

## 📌 Aprendizados

Este estudo prático me permitiu compreender na prática como ferramentas de automação podem agilizar o desenvolvimento, garantindo consistência e performance. Os conceitos aprendidos aqui são aplicáveis em projetos mais complexos com outras ferramentas e frameworks.
